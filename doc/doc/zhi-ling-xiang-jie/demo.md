# /demo

## 解释

展示 bot 的一些样例与辅助工具入口。

## 用法

```
/demo
```

## 特性

* 会回复一条带按钮的消息，按钮包括：
  * **生成绘图示例**：点击后 bot 会用你当前 `image` 配置里的配色，配合一组模拟数据生成一张示例图，用于快速预览配色效果。
  * **打开调色版**：跳转到在线配色工具，方便你挑颜色。
* 生成的示例图只是一次性的展示，不会写入你的规则或订阅记录。
* 示例图里的节点名称、协议类型、速度数值都是模拟数据，与你的实际后端无关。

{% hint style="info" %}
示例图使用配置文件中的绘图配置，可以快速预览配色效果，仅供测试使用。
{% endhint %}
