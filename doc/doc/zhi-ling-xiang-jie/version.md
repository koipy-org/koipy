# /version

## 解释

输出 bot 当前的版本信息。

## 用法

```
/version
```

## 特性

* 任何人都可以使用，不需要权限。
* 输出内容包含三项：
  * **版本号**：当前 koipy 的版本。
  * **提交**：当前运行代码对应的 git commit 短哈希。编译版本会直接使用打包时写入的提交号。
  * **构建时间**：编译版本会显示构建时间。
* 消息会在一段时间后被自动删除。
* 反馈问题前建议先看一眼版本号，很多问题在升级后就已经消失了。
