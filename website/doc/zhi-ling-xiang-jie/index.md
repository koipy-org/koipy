# 指令详解

什么是bot指令（命令）？

bot 指令是一种以 `/` 开头的特殊文本。在 Telegram 中，这些特殊文本会触发特定效果。

在此文档中，我们约定 `< >` 尖括号表示本项目指令**描述的特殊占位符**，用于区分说明内容。在实际输入中不需要输入尖括号。举例：

```text
/test <订阅名>
```

在此案例中，`<订阅名>` 是占位描述符，实际你要输入的是：

```text
/test TAG
```

而不是连同尖括号一起输入。后面的例子里还会多次出现这类占位符，这里就不重复说明了。

## 指令总览

按权限等级从低到高排列：

### 游客可用

| 指令 | 说明 |
| --- | --- |
| `/help` | 展示可用指令 |
| `/version` | 输出版本信息 |
| `/id` | 获取你的 UID 与对话 ID |
| `/subinfo` | 查询订阅流量（受限，见该页说明） |
| `/about` | 关于此 bot |

### 用户可用

| 指令 | 说明 |
| --- | --- |
| `/test` | 发起测试任务 |
| `/speed` | 下行速度测试 |
| `/uspeed` | 上行速度测试 |
| `/topo` | 拓扑测试（等价于 `/analyze`） |
| `/invite` | 邀请一个目标进行测试 |
| `/re` | 快速重测上一次任务 |
| `/rule` | 创建规则 |
| `/remove` | 删除规则 |
| `/checkslave` | 检查后端在线情况 |
| `/demo` | 展示一些样例 |
| `/license` | 展示许可证信息 |

### 管理员可用

| 指令 | 说明 |
| --- | --- |
| `/panel` | 打开控制面板 |
| `/reload` | 热重载配置 |
| `/grant` | 授权用户 |
| `/ungrant` | 取消授权 |
| `/get` `/set` `/del` | 读写配置项 |
| `/lang` | 切换语言包 |
| `/log` | 查看运行日志 |
| `/nightshift` | 开关夜间模式 |
| `/setantigroup` | 开关防拉群 |
| `/leave` | 让 bot 退出群组 |
| `/reboot` | 重启程序 |
| `/killme` | 结束进程 |
